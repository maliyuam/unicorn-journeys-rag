# Pinned for reproducibility.
#
# Retrieval quality depends on library and model versions, so a floating `>=`
# range means two people running the same golden set can legitimately get
# different numbers and neither can tell why. Exact pins make a run
# reproducible; `requirements-dev.txt` holds the tooling.
#
# To upgrade: change a pin, run
#     EVAL_GOLDENS_FILE=goldens.samples.json python scripts/evaluate.py --retrieval
# and put the before/after numbers in the PR. Do not bump these casually — the
# embedding and reranker models are what retrieval quality actually rests on.
#
# Verified together on Python 3.11, 3.12 and 3.14.
